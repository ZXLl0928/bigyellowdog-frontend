💾 存储与备份

数据默认存在浏览器里（清缓存会丢）。连接数据文件后，每次修改会自动写入你本地的 JSON 文件，换浏览器、换电脑都不丢。

· 需使用 Chrome / Edge 浏览器；Safari、Firefox 不支持文件落盘，请用「立即备份」手动导出。
· 连接后文件句柄会记在本浏览器，下次打开自动重连，无需重复选择。
· 设置备份目录后，每天首次打开会自动生成 Flyelep_备份_YYYY-MM-DD.json。

📖 使用提示

  • 每天打开先看顶部「今日已更新 / 尚未录入」提示，保持 1 视频 + 1 热点的节奏。
  • 「登记数据」中先在「账号管理」添加账号，再录入视频数据。
  • 顶部月份选择器只影响「总览」和「视频数据列表」的「仅本月」范围。
  • 客咨率 = 客咨 / 播放 × 100%，自动计算无需手填。
  • 导出的 JSON 可在另一台电脑/浏览器导入，实现备份迁移。
  • 清空操作不可恢复，请先导出备份。
